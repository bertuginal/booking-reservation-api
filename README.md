<h2 align="center">Booking & Reservation API 🚀</h2>
<h2 align="center">Techcareer .Net Core Domination Bootcamp</h2>

A structured RESTful API engineering solution developed using C# and .NET Core, designed to model corporate booking pipelines, client structures, and room reservation workflows. Developed as a core backend application during the Techcareer .NET Core Domination Bootcamp.

---

## 🗂️ Technical Scope & Model Relations

* **Relational Domain Design**: Modeled and bound primary transactional entities including Companies, Clients, and Rooms under a central Reservation logic.
* **REST API Endpoints**: Architected structured API Controllers implementing unified CRUD workflows (GET, POST, PUT, DELETE) across all sub-models.
* **Data Persistence**: Integrated Entity Framework Core with DbContext layers to handle automated records tracking and transaction persistence inside MSSQL Server.

## 🛠️ Tech Stack

* **Language**: C#
* **Framework**: .NET Core (Web API)
* **Database Management**: MSSQL (Microsoft SQL Server)
* **Data Access Layer**: Entity Framework Core (EF Core)

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the application project directory:
   ```bash
   cd booking-reservation-api/NetBootcampProject
   ```
3. Update your connection strings in the local app configuration profile.
4. Execute database migration updates and spin up the runtime server:
   ```bash
   dotnet ef database update
   dotnet run
   ```
